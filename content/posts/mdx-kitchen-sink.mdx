## Code

Fenced blocks get syntax highlighting in both light and dark mode:

```ts title="lib/posts.ts"
export function getAllPosts(): Post[] {
  return fs
    .readdirSync(POSTS_DIR)
    .filter((f) => /\.mdx?$/.test(f))
    .map(readPost)
    .sort((a, b) => (a.date < b.date ? 1 : -1));
}
```

Add `title="..."` after the language for the filename header. Use
`{2-4}` after the language to highlight specific lines.

## Tables

| Frontmatter | Required | What it does                        |
| ----------- | -------- | ----------------------------------- |
| `title`     | yes      | Post heading, tab title, OG title   |
| `date`      | yes      | Sort order and the displayed date    |
| `description` | no     | Card blurb and meta description     |
| `tags`      | no       | Powers the filter chips on /blog    |
| `published` | no       | `false` keeps it out of production  |
